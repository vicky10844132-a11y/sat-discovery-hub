Help / Documentation

This panel contains definitions, data modes, algorithm notes and limitations so operational screens remain concise.

Data modes

  • LIVE — operational backend or algorithm is connected.
  • SIMULATED — deterministic test data or workflow simulation.
  • CONNECTOR_REQUIRED — architecture preserved but external engine/provider is not connected.

Mission Copilot

The command interface must resolve OBJECTIVE, AOI, DATA_SEARCH, OPPORTUNITY, WEATHER/RESOURCE, CONTACT, SCHEDULE, PROCESS and DELIVER. It uses the canonical /v1/copilot/mission API when available and a clearly labelled SIMULATED fallback on static GitHub Pages.
