HELP / DOCUMENTATION

Mission Planning & Scheduling

PLAN turns an objective and AOI into ranked executable mission plans. It combines candidate spacecraft, opportunity geometry, spacecraft resource constraints, weather, ground-contact feasibility, conflicts, processing and delivery targets.

  • Generate Plans recalculates prototype ranking using the visible constraints.
  • Ranked Plans are alternatives; selecting one updates the execution schedule.
  • Commit represents accepting a plan into operations. In this prototype it is simulated.
  • Conflicts stay explicit rather than being hidden by automation.
