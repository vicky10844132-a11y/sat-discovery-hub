HELP

Mission Planning & Scheduling

PLAN converts an objective and AOI into constrained, ranked execution alternatives using canonical spacecraft and ground assets.

  • All candidate times and resource values in this page are explicitly simulated scenario data.
  • Validation is deterministic and checks required fields and time range.
  • Cloud, elevation, battery, optical/SAR, partner-ground and preemption constraints participate in filtering.
  • Ranking preference deterministically changes plan ordering; no unexplained numeric score is shown.
  • Plan acceptance is a simulated planning action, not live command uplink.
