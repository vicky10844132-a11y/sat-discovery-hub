Global Operations

OPS is the command layer for global situation awareness, mission initiation, active mission state, exceptions, contacts and operational health. Values in this prototype are simulated unless connected to a production service.

Interaction model

Layer toggles control the situation map. Mission Copilot creates a ranked executable path. Mission Queue opens active mission context. SYNC refreshes operational timestamps and emits a system acknowledgement.
