Archive policy: Direct Read first. Use selective extraction only when an operation requires random access.

Supported preview checks: file selection, naming heuristics, PAN/MS/RPC/metadata candidates, product readiness, settings, output folder capability, worker health, manifest generation and preflight report.

Real compute: GDAL/Rasterio/OpenCV/RPC workflows run through the local processing engine. The browser will not fabricate PASS, outputs or completed products.

QA gate: No product is considered final or deliverable until final QA is completed and signed off.
